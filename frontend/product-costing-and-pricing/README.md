# Product Costing & Pricing — Sakura Beaded Bags Frontend

Git branch: `frontend/product-custing-and-pricing`

## Contents
- `index.php` — PHP-rendered responsive frontend page with illustrative demo records.
- `assets/app.css` — responsive Sakura visual system (desktop, tablet, and phone breakpoints).
- `assets/app.js` — local UI interactions (search, filters, modal controls, calculators).

## Run locally
1. Install/start XAMPP, Laragon, or another PHP 8+ web server.
2. Copy this folder under the web server document root.
3. Open `http://localhost/product-custing-and-pricing/index.php` (adjust the folder path if you rename it).

## Important
This is a **frontend PHP preview**. Demo rows and form interactions are not stored in a database. Connect forms and actions to your team's authenticated PHP/MySQL endpoints before production. No credentials or database schema are included.
